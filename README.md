
# My Profile Page 
## Description
 This project is a personal profile webpage created using HTML, CSS and Javascript.It presents information about me,my intrests,skills, and other personal details in a simple and organized layout.
 ## Technologies Used 
 - HTML5
 - CSS3
 - Javascript
 ## Features 
 - Personal profile information 
 - Navigation bar 
 - Profile image 
 - About section 
 - Skills section 
 - Contact information 
 - Responsive and styled layout 
 - Interactive features using Javascript
 ## Project Structure
  - `index.html` - Contains the structure and content of the webpage. 
  - `index.css` - Contains the styling and layout of the webpage. - 
  - `README.md` - Provides information about the project.
  - `index.js` -provides information about the project and explain its files and technologies
  ##How to View the Project
  1. Clone or download the repository.
  2. Open the project folder.
  3. Open index.html in a web browser.
